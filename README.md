# Soundance

**让每个 App 的声音，各就其位。**

Soundance 是一款面向 macOS 的菜单栏音频工具，把应用音量、设备切换、音效和场景配置集中在一个中文面板里。压低背景音乐、切换耳机、为不同应用选择输出，日常调音不用在多个设置页面之间来回寻找。

**当前版本：0.7.6** · macOS 14.2+ · Apple Silicon

## 从一个面板，管理日常声音

### 每个 App，单独调节

分别调整应用的音量和静音状态，让音乐、视频和会议声音保持合适的比例。需要集中听一个音源时，可以使用“独听”，临时静音其他被 Soundance 识别并处理的应用。

应用设置可以记忆，下次使用时不用从头调整。

### 声音去哪里，由你选择

快速切换耳机、扬声器和麦克风，也可以为单个 App 指定输出设备。

常用设备支持别名和排序；自动切换另有独立的候选名单与优先级，整理常用列表不会改变自动切换规则。指定输出离线时，可选择暂时静音或跟随系统输出。

### 把一组设置，保存为场景

将输入输出设备、音量、应用配置和音效保存为场景，为工作、会议、音乐等使用方式准备自己的声音配置。

场景应用后，如果继续手动调节，界面会标记“已调整”，方便判断当前配置与保存内容是否一致。

## 更多控制，按需展开

- **设备级五段均衡器**：为不同输出设备分别保存 EQ 设置，提供 80 Hz、250 Hz、1 kHz、4 kHz、12 kHz 五个频段和音色预设。
- **音量增强**：为输出设备开启最高约 +6 dB 的软件增益。实际效果受音源和峰值限制影响，系统音量百分比保持不变。
- **多设备播放**：配置 2–4 个输出设备，同时播放经过 Soundance 处理的应用音频，分别调整各路软件音量。
- **快捷操作**：自定义面板、静音、音量增减和循环切换输出的快捷键，也可在菜单栏图标上滚动调节系统音量。
- **音量记忆**：分别保存应用与设备设置，减少重复调整。
- **中文与明暗外观**：菜单栏入口、中文界面、紧凑模式，以及区分输入与输出的音量浮窗。
- **统一处理开关**：暂停软件音频处理时保留配置，需要时再恢复。设备支持的系统音量控制仍可使用。

## 系统要求

- **操作系统**：macOS 14.2 或更新版本。
- **芯片支持**：Apple Silicon。
- **权限**：分应用音频处理需要按系统提示授予音频录制相关权限；连接已配对蓝牙设备时可能需要蓝牙权限。
- **网络**：试用期间及首次授权激活需要联网。

## 下载与安装

前往 [Releases](https://github.com/beige826/Soundance/releases/latest) 获取最新版本，以下两种安装方式任选其一。

### DMG 安装

1. 下载 [Soundance-0.7.6.dmg](https://github.com/beige826/Soundance/releases/download/v0.7.6/Soundance-0.7.6.dmg)。
2. 打开磁盘映像，将 **Soundance** 拖到旁边的 **Applications（应用程序）** 文件夹。
3. 复制完成后推出安装磁盘，从“应用程序”文件夹打开 Soundance。

### ZIP 安装

1. 下载 [Soundance-0.7.6.zip](https://github.com/beige826/Soundance/releases/download/v0.7.6/Soundance-0.7.6.zip)。
2. 解压，将 **Soundance.app** 拖入“应用程序”文件夹。
3. 打开 Soundance，按照应用提示完成设置。

Soundance 运行后显示在菜单栏。更新已有版本时，请先退出正在运行的 Soundance，再替换应用。

请下载名称为 **Soundance-版本号.dmg** 或 **Soundance-版本号.zip** 的附件。GitHub 自动生成的 **Source code** 附件是本仓库文件快照，不是应用安装包。

## 权限与隐私

Soundance 使用系统提供的音频接口处理应用声音。音频在本机实时处理，不保存录音，也不上传音频内容；设置保存在本机。

系统出现音频录制相关权限提示，是因为分应用调音需要访问应用输出的音频。权限页面的具体名称可能因 macOS 版本不同而变化。

试用验证会向授权服务发送设备标识摘要；激活时还会发送授权码，用于验证授权并绑定当前 Mac。上述请求不包含音频内容。

## 使用前请了解

- **按应用调节，不按浏览器标签页调节。** 同一个浏览器内的音频按整个 App 处理。
- **系统音量控制取决于设备能力。** 部分显示器或数字输出不提供可调节的系统音量，当前不含 DDC 音量控制；麦克风音量和静音同样取决于设备支持。
- **多输出不保证完全同步。** 蓝牙与有线设备可能存在不同的固定延迟。
- **当前分应用处理面向单声道或双声道。** 多声道设备、受保护音频、专业音频软件和特殊输出链路需要单独验证。
- **已保存的静音设置不等于始终静音成功。** 暂停或处理失败时，原始声音可能继续播放；请结合界面中的实际处理状态判断。
- **蓝牙设备需要先在 macOS 中配对。** 自动切换规则不会主动连接离线蓝牙设备。
- **避免多个工具同时接管同一音频链路。** 如出现重复播放、异常静音或切换问题，请先检查是否有其他音频处理软件同时工作。
