# Soundance 声动

**让每个 App 的声音，各就其位。**

Soundance 是一款 Mac 菜单栏音频工具。压低背景音乐、把会议声音送到耳机，或和朋友戴着各自的耳机一起看剧，都可以在一个面板里完成。

- **免费版**：分别调节各 App 的音量，切换耳机、音箱和麦克风，记住常用音量，设置快捷键和外观。

## 安装与使用

1. 打开下载的 DMG，把 Soundance 拖入「应用程序」。如果下载的是 ZIP，先解压，再把 Soundance 拖入「应用程序」。
2. 打开 Soundance，在菜单栏点击图标开始使用。单独调节 App 音量时，请按提示授予音频权限。Soundance 不保存录音，也不上传声音。

从 GitHub 下载时，请选择 **Soundance-1.4.dmg** 或 **Soundance-1.4.zip**。遇到 macOS 安全提示、设备兼容或其他使用问题，可查看[使用帮助](https://soundance.top/guide)。
