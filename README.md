# Soundance 声动

**让每个 App 的声音，各就其位。**

Soundance 是一款 Mac 菜单栏音频工具。调节每个 App 的音量、切换耳机和音箱、保存常用的声音设置，都可以在一个面板里完成。

[下载 Mac 版](#下载与安装) · [官网](https://soundance.top) · [使用帮助](https://soundance.top/guide)

## 功能介绍

### 日常声音控制 · 免费

| 功能 | 可以做什么 | 使用场景 |
| --- | --- | --- |
| 分应用音量 | 分别调节各 App 的音量，让音乐、视频和会议保持合适的比例。 | 开会时调小背景音乐，会议声音保持清晰。 |
| 系统与麦克风控制 | 在菜单栏里调整系统音量、静音和麦克风，无需来回打开系统设置。 | 开会前快速检查输入音量，需要时一键静音。 |
| 输入、输出设备切换 | 手动切换耳机、音箱和麦克风，也能连接已配对的蓝牙设备。 | 从音箱切到耳机，或改用外接麦克风。 |
| 音量记忆 | 记住不同 App 和设备的音量设置，减少反复调整。 | 音乐 App 保持较轻的音量，会议 App 保持较高的音量。 |
| 设备整理 | 给设备设置易认的别名，调整常用设备的显示顺序。 | 把不易辨认的设备名改成「桌面音箱」「会议耳机」。 |
| 自定义快捷键 | 为面板开关、系统静音、音量增减和切换输出设置快捷键。 | 工作时用键盘快速调整声音。 |
| 外观与布局 | 五套主题，支持浅色、深色和跟随系统；可调节主面板玻璃效果，使用紧凑模式和音量浮窗。 | 按自己的桌面风格与使用习惯设置面板。 |

### 更多声音玩法 · Pro

| 功能 | 可以做什么 | 使用场景 |
| --- | --- | --- |
| 应用静音与独听 | 单独静音某个 App，或用「独听」暂时静音列表里的其他 App。 | 专心听会议或视频，临时关掉其他应用的声音。 |
| 分应用输出 | 为不同 App 分别选择输出设备，同时在各自的设备上播放。 | 会议走耳机，音乐走音箱，不用反复切换系统输出。 |
| 多设备播放 | 同时使用 2–4 个输出设备，并分别调节每个设备的音量。 | 两个人各戴一副耳机一起看剧，各自调整到舒服的音量。 |
| 五段均衡器与音色预设 | 为不同输出设备分别调节音色，直接选用预设或自行调整。 | 为耳机和音箱保存不同的声音风格。 |
| 音量增强 | 在音源声音偏小时，进一步提高播放音量。 | 听清音量偏小的视频、课程或录音。 |
| 声音场景 | 将输入输出设备、音量、应用配置和音效保存成场景，随时一键恢复。 | 为工作、开会、听歌各存一套设置，下次直接切换。 |
| 自动切换输出 | 按你设置的设备名单与优先级，自动选择可用的输出设备。 | 在耳机和音箱之间按常用顺序切换。 |
| 菜单栏滚轮调音量 | 在 Soundance 菜单栏图标上滚动，即可调整系统音量。 | 不打开面板，也能随手调大或调小声音。 |

分应用音量按整个 App 调节，同一浏览器里的标签页共用音量。多个设备同时播放时，不同设备之间可能有延迟；系统音量和麦克风调节取决于设备支持。

## 下载与安装

适用于 Apple 芯片（M 系列）的 Mac，需要 macOS 14.2 或更新版本。

[下载 DMG](https://soundance.top/downloads/Soundance-1.4.dmg) · [下载 ZIP](https://soundance.top/downloads/Soundance-1.4.zip) · [GitHub 备用下载](https://github.com/beige826/Soundance/releases/latest)

### 安装步骤

1. 下载并打开 DMG，把 Soundance 拖入旁边的「Applications / 应用程序」文件夹；如果下载的是 ZIP，先解压，再把 Soundance 拖入「应用程序」。
2. 从「应用程序」打开 Soundance。启动后，点击菜单栏里的 Soundance 图标即可开始使用。
3. 更新已有版本时，请先退出正在运行的 Soundance，再替换安装。

从 GitHub 下载时，请选择 **Soundance-1.4.dmg** 或 **Soundance-1.4.zip**，不要选择自动生成的「Source code」附件。

### 首次打开遇到 macOS 安全提示

如果提示「Apple 无法验证」或「无法验证开发者」，请先确认安装包来自本官网或本仓库的 Releases 页面，然后按以下步骤操作：

1. 先尝试打开一次 Soundance；出现提示后关闭提示窗口。
2. 打开 Mac 的「系统设置 → 隐私与安全性」，向下找到关于 Soundance 的提示，点击 **「仍要打开」**。
3. 在再次出现的确认窗口中选择「打开」，并按系统要求完成确认。

完成后，之后通常可以直接从「应用程序」打开 Soundance。如果没有看到「仍要打开」或仍无法启动，请将系统版本和提示截图发给[支持邮箱](mailto:amosleung0826@outlook.com)。也可参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

单独调节 App 音量时，macOS 可能会请求音频录制权限。Soundance 在本机处理声音，不保存录音，也不上传声音。
