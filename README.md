# Soundance 声动

**让每个 App 的声音，各就其位。**

Soundance 是一款 Mac 菜单栏音频工具。调节每个 App 的音量、切换耳机和音箱、保存常用的声音设置，都可以在一个面板里完成。

[下载 Mac 版](#下载与安装) · [官网](https://soundance.top) · [使用帮助](https://soundance.top/guide)

## 功能介绍

### 每个 App，单独调音量

开会时把音乐调小，会议音量保持不变。Soundance 会记住各 App 的音量，下次打开不用重调。分应用音量免费使用；Pro 还可以单独静音某个 App，或用「独听」只留下想听的声音。

### 两副耳机，一起看同一部剧 · Pro

让同一台 Mac 的声音同时在 2–4 个设备上播放。两个人各戴一副耳机一起看剧，每副耳机的音量可以分别调节。

### 会议走耳机，音乐走音箱 · Pro

给不同 App 指定各自的输出设备。开会时用耳机听会议，音乐可以继续从音箱播放，两边互不打断。

### 工作、开会、听歌，一键切换 · Pro

把设备、音量和音效保存成声音场景。比如为会议保存耳机和麦克风设置，为听歌保存音箱和均衡器设置，下次直接切换。

### 常用控制，都在菜单栏

- **免费版**：快速切换耳机、音箱和麦克风，给设备改名，自定义快捷键和外观。
- **Pro**：用均衡器调整音色，用音量增强提高偏小的声音，按优先级自动切换输出，或在菜单栏图标上滚动调节音量。

## 下载与安装

适用于 Apple 芯片（M 系列）的 Mac，需要 macOS 14.2 或更新版本。

[下载 DMG](https://soundance.top/downloads/Soundance-1.4.dmg) · [下载 ZIP](https://soundance.top/downloads/Soundance-1.4.zip) · [GitHub 备用下载](https://github.com/beige826/Soundance/releases/latest)

打开 DMG，或解压 ZIP，将 Soundance 拖到「应用程序」。打开后，在菜单栏点击 Soundance 图标开始使用。从 GitHub 下载时，请选择以 `.dmg` 或 `.zip` 结尾的 Soundance 安装包。

单独调节 App 音量时，macOS 可能会请求音频录制权限。Soundance 在本机处理声音，不保存录音，也不上传声音。
